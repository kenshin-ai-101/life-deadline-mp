# 云开发部署指南（数据上云改造）

本文描述把「人生时限」从纯本机存储切换到「本机缓存 + 微信云开发主库」的完整步骤。
代码侧改造已全部完成，剩余工作都是控制台配置，预计 30 分钟内可完成。

---

## 0. 架构一句话

- **内容数据**（772 条建议、急救卡）继续打包在代码包里，不发请求。
- **用户数据**（事件、待办、成员、收藏、回执、设置）写本机即生效，`utils/sync.js` 异步同步到云端主库。
- **小程序端不直连数据库**，所有读写走云函数 `dataSync`，openid 由云函数上下文提供，无法伪造。
- **敏感字段**（成员卡的姓名/年龄/性别/主要状况）在云端以 AES-256-GCM 加密落库，密钥按账号派生。
- 未配置云环境时自动退化为纯本机模式，所有功能可用（审核兜底、本地开发都不受影响）。

涉及文件：

| 文件 | 职责 |
| --- | --- |
| `utils/config.js` | **唯一需要手填的地方**：云环境 ID |
| `utils/cloud.js` | wx.cloud 初始化、callFunction 超时与重试 |
| `utils/sync.js` | 登录 / 首次迁移 / 增量推拉 / 合并 / 状态广播 |
| `utils/store.js` | 本机缓存层（对外 API 不变），脏标记 + 删除墓碑 |
| `cloudfunctions/dataSync/` | 云函数：lib/ 为可单测纯逻辑，index.js 为编排 |
| `pages/privacy/privacy` | 隐私政策 + 数据权利（导出 / 删除 / 撤回授权） |

## 1. 开通云开发并拿到环境 ID

1. 微信开发者工具打开本项目 → 工具栏「云开发」→ 开通（个人主体可用按量付费的免费额度）。
2. 创建环境，地域建议选「上海」或「广州」（大陆节点，合规要求）。
3. 复制**环境 ID**（形如 `life-deadline-6g1a2b3c`），填入 `utils/config.js`：

```js
cloudEnv: 'life-deadline-6g1a2b3c',   // ← 填这里
```

留空即为纯本机模式。

## 2. 上传云函数

1. 开发者工具左侧资源管理器会出现 `cloudfunctions` 目录。
2. 右键 `cloudfunctions/dataSync` → **「上传并部署：云端安装依赖（不上传 node_modules）」**。
3. 等待部署完成（约 1-2 分钟）。

命令行方式（可选）：

```bash
# 在开发者工具已打开本项目的情况下
miniprogram-ci 不支持云函数部署，请使用开发者工具或 cloudbase CLI
```

## 3. 设置加密密钥（必须）

云开发控制台 → 云函数 → `dataSync` → 配置 → **环境变量**，添加：

```
PII_SECRET = <一串足够长的随机字符串，至少 32 位>
```

生成示例：`openssl rand -hex 32`

> ⚠️ 此密钥用于加密成员卡的敏感字段，一旦有用户数据就不要更换（换了老密文解不开）。
> 未配置时使用开发默认值，功能可用但**上线前必须配置**（`health` 动作会返回 `piiSecretConfigured` 供自检）。

## 4. 建集合（10 张）

云开发控制台 → 数据库 → 逐一创建以下集合。名称必须一致：

| 集合 | 用途 |
| --- | --- |
| `ld_users` | 用户档案：迁移标记、授权记录、删除墓碑 |
| `ld_events` | 人生事件 |
| `ld_tasks` | 时限任务 / 书中动作 |
| `ld_members` | 家庭成员卡（敏感字段加密） |
| `ld_receipts` | 回执（备注文本；图片走文件存储，见 §7） |
| `ld_favorites` | 条目收藏 |
| `ld_chapter_favs` | 章节收藏 |
| `ld_chapter_likes` | 章节点赞 |
| `ld_settings` | 阅读偏好等设置 |
| `ld_track` | 匿名使用统计（用户主动勾选后才写入） |

### 权限

所有集合统一设置为**「自定义安全规则」**，内容如下（拒绝一切客户端直连）：

```json
{
  "read": false,
  "write": false
}
```

客户端只通过云函数读写，云函数使用服务端 SDK 不受此规则限制。
这样即使有人拿到用户端调试权限，也无法绕过身份校验直接读别人的数据。

### 索引

每个 `ld_*` 数据集合（除 `ld_users`）建一条**组合索引**：

```
_openid  升序  +  updatedAt  升序
```

没有这条索引，增量拉取（`where({_openid, updatedAt >= since})`）在数据量大时会全表扫描并可能超时。
控制台 → 数据库 → 集合 → 索引管理 → 添加。

## 4.5 敏感信息授权门禁（已内置，无需配置）

成员卡里的姓名、年龄、性别、主要状况属于敏感个人信息，链路上有三道闸，全部是代码强制的：

1. **客户端不上传**：`utils/sync.js` 的 `buildChanges` 在「未单独同意」时直接跳过 `members` 集合；
   用户勾选同意后自动把成员卡重新标脏补推（`pushConsent`）。
2. **服务端不落库**：云函数 `handleSync` 校验 `ld_users.sensitiveConsent`，未授权时拒收 members 并返回
   `blocked:['members']`，客户端会补推同意后重试。即使有人改造客户端直推，也进不了库。
3. **撤回即物理删除**：`consent` 动作里 `sensitiveConsent:false` 会立刻物理删除 `ld_members` 中该用户全部文档
   （返回 `purgedMembers` 计数），不是软删、不是只改标志位。拉取侧同样不下发 members，防止其他设备把数据拉回来。

加密本身不受门禁影响：只要落库，敏感字段一律先过 AES-256-GCM（密钥 = sha256(PII_SECRET|openid)）。
验证方法：撤回授权后查 `ld_members`，该 openid 的文档应为 0 条。

## 5. 验证部署

在开发者工具控制台（模拟器）里依次确认：

1. **重启小程序** → 「我的」页出现「已开启云端同步」，状态点亮绿色。
2. 首次启动会自动把本机已有数据推上云（迁移，幂等，重复触发不会重复写）。
3. 云开发控制台 → 数据库 → `ld_users` 里出现你的记录，`migrated: true`。
4. 新建一个事件 → 1-2 秒后 `ld_events` 出现对应文档，字段带 `updatedAt`。
5. 删除该事件 → 文档变为 `deleted: true`（软删墓碑，防多端复活）。
6. 自检接口（可临时在 `app.js` 里调）：

```js
wx.cloud.callFunction({ name: 'dataSync', data: { action: 'health' } })
  .then(r => console.log(r.result))
// 期望：{ ok: true, piiSecretConfigured: true, collections: [...] }
```

## 6. 数据流向与冲突策略（写给未来维护者）

- **一轮同步 = 推送脏集合 → 按 `updatedAt >= since` 拉增量 → 合并进本机缓存。**
- 时间戳一律由服务端打，避免多端时钟偏差；策略是**最后同步者胜出**（last-write-wins）。
  单人多设备场景够用；如果未来要做协作，再升级字段级合并。
- 删除是软删墓碑（`deleted: true`），否则 A 设备删掉的数据会被 B 设备同步回来。
- `settings` 是单文档整份覆盖；收藏类是值即主键的去重集合。
- 本机不同步的键：搜索历史（隐私考量）、埋点计数（opt-in 后只报「功能名 + 次数」）、
  同步元数据、授权记录（授权在 `ld_users` 单独留痕）。

## 7. 回执图片（当前版本未上传）

回执目前只同步备注文本，图片留在本机。如需图片上云：

1. 云存储建目录 `receipts/{openid}/`；
2. 客户端压缩后 `wx.cloud.uploadFile`，把 `fileID` 存进回执记录（当前 `images` 字段直接可放 fileID）；
3. 读取用 `wx.cloud.getTempFileURL` 换临时链接；
4. 删除账号时同时 `wx.cloud.deleteFile`，否则存储里会留孤儿文件。

## 9. 已知限制

- 回执图片不同步（见 §7）。
- 同一记录多端同时编辑时最后同步者胜出，不做字段级合并。
- 增量拉取单次上限 2000 条文档（`hasMore` 分页自动续拉），单次推送上限 500 条。
- 软删墓碑永久保留；数据量极大时可在云函数里加定期清理（90 天前的 `deleted: true` 文档）。
